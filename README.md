# 🦀 Embedded Rust Journey: ESP32 `no_std`

A chronicle of my journey learning bare-metal embedded Rust. This repository contains a collection of small projects and hardware experiments, progressively building up to more complex embedded systems. 

All projects here are written in `#![no_std]` (bare-metal) environments, interacting directly with hardware peripherals without an underlying operating system.

## 🛠️ Hardware Profile
*   **Microcontroller:** ESP32 WROOM (Xtensa dual-core 32-bit LX6)
*   **Framework:** `no_std` (Bare-metal / `esp-hal`)
*   **Editor:** Visual Studio Code
